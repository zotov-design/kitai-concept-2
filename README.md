# Китай Concept 2

Адаптивная статическая вёрстка [макета V2](https://www.figma.com/design/Xq8R3pYULQUFJzBiVKFHpU/?node-id=50-781). Только состав этого макета: хедер, главный экран с фактами, четыре направления и пять рекомендуемых туров. Две дополнительные карточки добавлены по запросу владельца.

HTML, CSS, JavaScript ES modules. Установка пакетов и сборка для запуска не нужны. Все изображения, SVG и шрифты Onest локальные. В репозитории файлы сайта находятся в корне; в рабочем проекте — в `dist/`.

## Запуск

`node server.mjs` — открыть http://localhost:4174. Сервер автоматически выбирает `dist/`, если эта папка присутствует, иначе обслуживает корень репозитория.

## Взаимодействие

- Плавное однократное появление блоков снизу вверх через IntersectionObserver, без перехвата вертикального скролла. Поддерживается prefers-reduced-motion.
- Hover-состояния включаются для мыши. Иконки сохраняют положение; фон становится тёмно-синим, контур голубым. Мобильное меню закрывается по Escape, повторной кнопке, выбору пункта и нажатию вне хедера.
- Нативные горизонтальные ленты: свайп/трекпад, точечная пагинация на мобильном; кнопки и клавиатура на desktop. Четыре точки направлений, пять точек туров. На компьютере ленту туров можно перетаскивать зажатой левой кнопкой мыши; движение не открывает диалог карточки.
- Модальные окна закрываются по Escape, кнопке и нажатию на фон; фокус возвращается к исходной кнопке.

## Проверка и границы

27.10.2026: проверены 320, 360, 390, 430, 768, 1024, 1280, 1440, 1920 px во встроенном Chromium. Горизонтальное переполнение страницы и хедера — 0; отсутствующих изображений — 0. Desktop при ширине 1920 имеет высоту 2549 px, как исходный фрейм. Проверены меню, якоря, крайние положения лент, индикаторы и диалоги.

Отдельного mobile-фрейма в исходном файле нет: адаптация выполнена для V2 с учётом решений V1. Скриншоты и метрики сохранены локально в папке `qa/`. Курсоры-указатели на макете — служебные обозначения; в интерфейс сайта не перенесены. Первая карточка тура в основном фрейме показана в Hover: в вёрстке Default и Hover разделены.

Телефон в макете демонстрационный. Рабочих адресов страниц, контактов и API заявок не предоставлено: соответствующие действия открывают пояснение и не имитируют отправку. Содержание, цены и сочетания названий/изображений перенесены из макета без фактической проверки туристических предложений. Физический телефон, Safari/Firefox и инструментальная оценка FPS не проверялись.

Оригинальные PNG и lossless WebP сохранены локально; сайт использует оптимизированные WebP-производные с исходными композициями и кадрированием через CSS. Проект демонстрационный, установлен noindex.

## Сохранность материалов

Без явного разрешения владельца не удалять файлы, папки, данные, резервные копии и материалы в связанных сервисах. Общее поручение исправить или оптимизировать не разрешает удаление. Предыдущая V1 и исходный файл Figma сохранены.

## Обновление взаимодействия — 27.10.2026

Проверены наведение без смещения, фактическое перетаскивание мышью в обе стороны, отсутствие случайного открытия после drag, отдельный клик, край пятого тура и пять мобильных индикаторов. На 320 px исправлен минимальный размер карточки, чтобы её правая граница целиком помещалась в экран. Дополнительные карточки «Пекин» и «Чэнду» используют изображения проекта; цены и сроки для них не выдумывались.

## Рекомендуемые туры без появления — 27.10.2026

По запросу владельца у всего блока рекомендуемых туров, включая заголовок и пять карточек, отключено появление через opacity/translateY. Этот блок исключён из наблюдателя появления и не скрывается ни при вертикальной прокрутке страницы, ни при горизонтальном пролистывании. Фотографии туров загружаются заранее (eager). Сохранены плавное перемещение ленты, перетаскивание мышью, стрелки, мобильные точки и hover.
